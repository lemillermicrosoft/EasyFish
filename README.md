# EasyFish

A tiny quality-of-life addon for fishing in **World of Warcraft: TBC Classic (2.5.6)**.

**Concept:** double right-click anywhere in the empty game world while holding a fishing pole, and EasyFish will apply your preferred bait/lure to the pole for you.

## Status

Initial scaffold. Loads in-game and registers `/easyfish` (`/ef`) slash command. Core feature not yet implemented — coming soon.

## Install

1. Copy the `EasyFish` folder into `World of Warcraft\_anniversary_\Interface\AddOns\`.
2. Restart the client or `/reload`.

## Commands

- `/easyfish` or `/ef` — placeholder for now; will open config later.
